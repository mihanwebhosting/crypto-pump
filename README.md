# WhalePulse — ربات نهنگ‌یاب و سیگنال پامپ/دامپ 🐋

ردیابی تراکنش‌ها و کیف‌پول‌های نهنگ روی ۲۰۰ کوین برتر بازار (CoinGecko / CoinMarketCap) و صدور سیگنال **پامپ (LONG)** و **دامپ (SHORT)** پس از مشورت با هوش مصنوعی **Gemini**.

## قابلیت‌ها

- 📊 **۲۰۰ کوین برتر**: پایش زنده رتبه‌های ۱ تا ۲۰۰ بازار + کشف توکن‌های جدید (Wildcard) خارج از لیست
- 🐳 **رادار نهنگ**: تراکنش‌های ≥ $۱M از طریق Etherscan V2 و نودهای RPC عمومی (Ethereum / Base / Arbitrum)
- 🛡 **بررسی امنیت قبل از سیگنال**: هر کوین جدیدی که نهنگ‌ها بخرند/بفروشند، ابتدا ممیزی امنیت قرارداد (هانی‌پات، مالیات، قفل نقدینگی، Mint) را رد می‌کند و فقط در صورت قبولی سیگنال می‌شود
- 🤖 **مشاوره Gemini**: هر ستاپ پیش از ارسال، توسط Gemini تایید می‌شود (در صورت نبود کلید، موتور کمّی جایگزین فعال می‌شود)
- 📡 **ربات تلگرام ۲۴/۷**: ارسال خودکار سیگنال‌ها + ریپلای خودکار TP1 / TP2 / Stop Loss + آرشیو معاملات
- 📈 **سود/ضرر لحظه‌ای (PnL)**: نمایش زنده Entry / قیمت فعلی / PnL روی کارت هر سیگنال و پنل رهگیری ۲۴ ساعته — حتی برای توکن‌های Wildcard خارج از ۲۰۰ برتر (مثل Fartcoin ،TokenBot Clanker و ToxDistribution) که در فیدهای اصلی پوشش قیمتی ندارند
- 📊 **چارت زنده با قیمت واقعی برای همه کوین‌ها**: قیمت‌ها از یک آبشار منبع واقعی خوانده می‌شوند — **Binance klines** برای کوین‌های صرافی‌لیست‌شده، **GeckoTerminal** (قیمت توکن بر اساس آدرس قرارداد + کندل‌های OHLCV استخر DEX) برای کوین‌های Wildcard و فقط-DEX، **CoinGecko market_chart** و در نهایت **DexScreener**. چارت همراه با خطوط Entry / TP1 / TP2 / SL، میله‌های حجم، تایم‌فریم ۱h/۴h/۲۴h و نوار «ورود / قیمت فعلی / سود-ضرر لحظه‌ای / بیشترین سود» نمایش داده می‌شود. اگر هیچ منبع واقعی در دسترس نباشد، وضعیت به‌صورت صریح با برچسب زرد «شبیه‌ساز قیمت» اعلام می‌شود تا داده مصنوعی جای داده بازار جا نزند
- 🔒 **ضد تکرار**: هر نماد تا رسیدن به تارگت نهایی یا حد ضرر فقط یک‌بار سیگنال می‌گیرد (کول‌داون ۱۵ دقیقه‌ای پس از بسته شدن)

## متغیرهای محیطی (اختیاری ولی توصیه‌شده)

### 🔑 کلیدها را کجا وارد کنم؟

یک فایل به نام **`.env`** در ریشهٔ پروژه (کنار `package.json`) بسازید و کلیدها را داخل آن بنویسید. سرور در لحظهٔ استارت آن را به‌صورت خودکار می‌خواند (هم در `npm run dev` و هم در `npm start`).

ساده‌ترین راه:

```bash
cp .env.example .env
```

سپس فایل `.env` را باز کنید و مقادیر را پر کنید:

```env
GEMINI_API_KEY=AIza...
ETHERSCAN_API_KEY=K123...
TELEGRAM_BOT_TOKEN=123456:ABC...
TELEGRAM_CHAT_ID=123456789
```

در لاگ استارت سرور، وضعیت هر کلید با ✅ (تنظیم‌شده) یا ⚠️ (گم‌شده) چاپ می‌شود تا مطمئن شوید کلیدها درست خوانده شده‌اند. فایل `.env` در `.gitignore` قرار دارد و هرگز همراه کد آپلود نمی‌شود.

### جدول متغیرها

| متغیر | توضیح |
|---|---|
| `TELEGRAM_BOT_TOKEN` | توکن ربات تلگرام از BotFather — بدون آن ارسال تلگرام غیرفعال است |
| `TELEGRAM_CHAT_ID` | شناسه عددی چت شخصی برای دریافت همزمان سیگنال‌ها |
| `TELEGRAM_CHANNEL` | نام کانال مقصد (پیش‌فرض: `@nahang_yab`) |
| `GEMINI_API_KEY` | کلید Google Gemini برای تایید هوشمند سیگنال‌ها — دریافت رایگان از [aistudio.google.com/apikey](https://aistudio.google.com/apikey) |
| `ETHERSCAN_API_KEY` | کلید Etherscan V2 برای رصد تراکنش‌های نهادی — دریافت رایگان از [etherscan.io/apis](https://etherscan.io/apis) |
| `PORT` | پورت سرور (پیش‌فرض: `3000`) |

> ⚠️ هیچ توکن یا کلیدی را داخل کد هاردکد نکنید. تنظیمات ربات از طریق پنل تنظیمات داخل برنامه یا متغیرهای محیطی اعمال می‌شود.

## مسیرهای API اصلی

| مسیر | توضیح |
|---|---|
| `GET /api/signals` | سیگنال‌های فعال (پامپ/دامپ) با ضریب اطمینان و تارگت‌ها |
| `POST /api/signals/regenerate` | اسکن مجدد و تولید سیگنال‌های تازه |
| `GET /api/live-transactions` | فید زنده تراکنش‌های نهنگ (≥ $۱M) |
| `GET /api/market/scanned-tokens` | کل جهان پایش‌شده (۲۰۰ کوین برتر + کشف‌های جدید) |
| `GET /api/bot/status` | وضعیت ربات تلگرام (توکن فقط به صورت ماسک‌شده) |
| `GET /api/chart/candles?symbol=BTC&range=1h` | کندل‌های واقعی (Binance → GeckoTerminal → CoinGecko → DexScreener) + Entry/TP/SL + سود/ضرر لحظه‌ای + منبع قیمت |
| `GET /api/chart/price-history?symbol=BTC` | همان پایانه‌ی بالا (برای سازگاری با نسخه‌های قبل) |
| `POST /api/bot/config` | به‌روزرسانی تنظیمات ربات |
| `POST /api/gemini/consult-signal` | مشورت لحظه‌ای Gemini برای یک نماد |
| `GET /api/bot/muted` | فهرست نمادهای بی‌صدا (Mute) |
| `POST /api/bot/mute` | بی‌صدا کردن یک/چند نماد — `{ symbol \| symbols, minutes?, reason? }` |
| `POST /api/bot/unmute` | لغو بی‌صدا — `{ symbol }` یا `{ all: true }` و گزینه‌ی `regenerate: true` |
| `POST /api/bot/clear-and-regenerate` | بازنشانی همگام داشبورد و تلگرام — `broadcast: "auto" \| "force" \| "silent"` |

### 🎯 قیمت ورود واقعی (نه قیمت دمو)

«تارگت رسید!»های اشتباه از یک ریشه می‌آمدند: قیمت ورود با `LIVE_PRICES_CACHE[sym]?.price || token.price`
گرفته می‌شد و برای کوین‌های wildcard آن `token.price` یک عدد دموی کاتالوگ بود؛ بعد همان سیگنال با
قیمت واقعی مقایسه می‌شد و در اولین تیک «تارگت ۱ و ۲ زده شد» می‌خورد (خطای +۱۱٬۰۰۰٪).

- `resolveRealEntryPrice()` تنها مرجع قیمت ورود است: اول فید واقعی، در صورت نبود یک درخواست تازه به
  زنجیره‌ی Binance → GeckoTerminal → CoinGecko → DexScreener، و در نهایت شبیه‌ساز قیمت **با پرچم `isReal: false`**.
- `isTrackedPriceVerdictTrustworthy()` + `evaluateSignalOutcome()`: تا قیمت زنده از فید واقعی نیاید،
  هیچ داوری TP/SL صادر نمی‌شود (PnL در داشبورد همچنان حرکت می‌کند).
- اگر لنگر قیمت مشکوک باشد (`|انحراف| > ۵۰٪` در ۵ دقیقه اول باز شدن معامله)، `reanchorSignalEntry()`
  آن را با قیمت واقعی بازمحاسبه می‌کند و تارگت‌ها را از نو می‌سازد — به‌جای ارسال هشدار غلط.
- متن پیام تلگرام و محاسبات رهگیر، هر دو از **یک** عدد قیمت ورود استفاده می‌کنند؛ اگر فید واقعی نبود،
  پیام صریحاً می‌گوید نقطه ورود تخمینی است.
- پاسخ `/api/signals` سه فیلد راستی‌آزمایی دارد: `entryPriceSource`، `entryPriceIsReal`، `priceIsReal`
  (و کارت سیگنال همین‌ها را روی برچسب «قیمت ورود» نمایش می‌دهد).

### 🔕 بی‌صدا کردن نماد (Symbol Muting)

فهرست بی‌صداها در `.runtime/muted_symbols.json` ذخیره می‌شود و بعد از ری‌استارت هم برجا می‌ماند.
نماد بی‌صدا: از تولید سیگنال، از برادکست تلگرام و از همه‌ی ریپلای‌های TP1/TP2/SL حذف می‌شود؛ سیگنال
فعالِ آن در داشبورد همچنان PnL می‌گیرد و هنگام لغو بی‌صدا، پیام انباشته‌ای به کانال ریخته نمی‌شود
(بسته‌شدن‌های دوران mute به‌صورت silent آرشیو می‌شوند). `minutes` برای بی‌صدای موقت است و خودش منقضی می‌شود.

### 📡 حالت‌های `broadcast` در بازنشانی/بازپخش

| حالت | رفتار |
| --- | --- |
| `auto` (پیش‌فرض) | فقط ستاپ‌های تازه‌ای که فعال یا در دوره استراحت ۱۵ دقیقه‌ای نیستند ارسال می‌شوند |
| `force` | دوره استراحت نمادهای ستاپ‌های تازه پاک می‌شود و ارسال **واقعاً** تکرار می‌شود (بدون سیگنال دوتایی روی یک نماد) |
| `silent` | فقط منوی سیگنال بازسازی می‌شود؛ هیچ ارسالی به تلگرام |

پاسخ این مسیرها حالا به‌جای یک عدد خالی، `dispatchSummary` کامل می‌دهد: `sent`، `failed`،
`skippedMuted`، `skippedDuplicate`، `skippedByGemini`، `anchoredOnRealPrice` / `anchoredOnEstimatedPrice`
و `botConfigured` — تا «چرا چیزی ارسال نشد» در UI قابل توضیح باشد.
